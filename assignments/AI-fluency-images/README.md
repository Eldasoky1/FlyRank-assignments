## The "one consistent style" rule
The only generated imagery under consideration was a subtle hero *texture*. Rule applied: one
texture prompt iterated to hold the kit's mood (light, calm, teal-tinged) — if it ever strayed
from `#f7f7f5`/`#07f49e`, it was rejected (see below). Because the site chose text-based hero, the
set ultimately needs **no generated images** — consistent by construction.

## The rejected generated image (discernment, graded)
> Generated a dark cyan aurora texture for the hero. **Rejected:** it fought the identity kit
> ("calm and confident — only the action gets colour"); a loud background would have cheapened the
> proof line and required a font stack that hurts load. Kept the flat canvas instead.
