# AI Fluency — Week 3 · Decide how it looks (Foundations)

**Deliverable:** the few simple intentional choices that make the site feel designed, not amateur.
("<The skill this week is judgment — telling good from bad and choosing well.">)

## The rule that carried the build
**Every choice must serve the one action** (contact with proof), so the site gets: one clean
typographic scale, one accent, generous whitespace, and zero decoration that doesn't earn its bytes.

## Choices made (judgment, not talent)
1. **Fonts:** system-ui stack + one accent font for the name/tagline only — two roles, one weight contrast. Kept a `font-sans` stack (no font download → fast, no FOUT).
2. **Colour:** near-black text on near-white canvas + a single accent (`#07f49e`) reserved for *actionable* elements (links, CTAs) — not for decoration.
3. **Mood (one sentence):** *"Calm and confident: a white lab coat with one green button — nothing competes with the thing I want you to click."*

## Judgment demo — what I rejected and why
- **Rejected:** a dark hero with a big gradient. It "looks designer-y" but forces the accent to fight the dark, and gradients predictably cheapen key-value proofs. **Kept:** flat light canvas, accent only on action.
- **Rejected (concretely):** a rainbow gradient CTA "Learn more" on the hero. It signals *more content*, not *the action*; the CTA is `mailto:`/booking only.

## Deliverable check
- Choices intentional and few (no design talent required) → 3 decisions above, each tied to the one action.
- Judgment shown (good vs bad chosen well) → the two rejections with reasons.
