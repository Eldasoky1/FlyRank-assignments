# FL-06 — Design Your Personal Agent

The spec for my capstone agent: a **weekly review scout** that agentizes the FL-04
pipeline (model-driven topic selection per FL-05's named upgrade) and merges my weekly log
into one mentor-review-ready brief with a human signoff gate.

- `agent-spec.md` — one-page design doc: job to be done, the user + frequency, tools/data
  with access plans, draft instructions, six pre-build eval cases (E1–E6), risks and
  guardrails, and the scripted-agent platform choice justified against Claude Project,
  n8n, and custom GPT.

FL-07 will build exactly this spec and show its end-to-end run.
